# FIFA Players Excel Dashboard

## Overview

This interactive Excel dashboard analyzes FIFA player statistics, skills, attacking performance, and player attributes using Pivot Tables, Pivot Charts, and Slicers.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis

## Dashboard Features

### Player Analysis
- Attacking Performance
- Player Skills Comparison
- Rating Distribution
- Player Statistics Analysis

### Interactive Filters
- Attacking Metrics
- Hits
- Nationality
- Age

### Visualizations
- Bar Charts
- Donut Charts
- Performance Analysis Charts

## Key Insights

- Compare player attacking attributes.
- Analyze player skill distributions.
- Filter player data dynamically using slicers.
- Identify top-performing player profiles.
